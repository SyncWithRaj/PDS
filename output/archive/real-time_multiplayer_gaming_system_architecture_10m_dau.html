1. System Overview

A production-grade, highly scalable Microservices architecture engineered for the Real-Time Multiplayer Gaming domain deployed natively on AWS. The architecture is organized into segregated tiers including global edge ingress with automated DDoS mitigation, stateless containerized microservices running on Amazon EKS (Kubernetes) autoscaling to handle a peak load of 10,416 QPS, an asynchronous event streaming backbone powered by Amazon MSK (Managed Kafka), and an 80/20 in-memory Redis cluster allocating 37 GB RAM for sub-5ms p99 read latencies. Data persistence is backed by Amazon Aurora PostgreSQL (Multi-AZ Multi-Region) with multi-AZ active replication supporting 764.9 TB across a 5-year operational lifecycle.

5. Architectural Trade-Off Analysis

Polyglot Persistence Layer

Chosen: Amazon Aurora PostgreSQL (Multi-AZ Multi-Region) + Redis Cache  |  Discarded: Single Monolithic Relational Database

Separating transactional persistence from an in-memory cache holding the 80/20 hot set (37 GB RAM) allows achieving sub-5ms read latency at 8,333 read QPS at the cost of cache-invalidation management.

Asynchronous Event Decoupling

Chosen: Amazon MSK (Managed Kafka)  |  Discarded: Direct Synchronous REST/gRPC Chained Calls

Decoupling core write operations via an event stream protects downstream services from cascading failures under peak load, trading immediate read-your-writes consistency for high availability and fault isolation.

6. Bottleneck Identification & Mitigation Strategies

⚠️ Traffic Surges Exceeding Peak Concurrency (10,416 QPS)

Mitigation Strategy: Deployed on Amazon EKS (Kubernetes) configured with Horizontal Pod Autoscaling (HPA) targeting ~6 pods, backed by edge rate limiting at the API Gateway.

⚠️ Single Point of Failure in Relational Database

Mitigation Strategy: Configured Multi-AZ Active-Active replication with automated failover and read replicas.

⚠️ Database Connection Pool Exhaustion on Flash Read Bursts

Mitigation Strategy: Deployed 3-node Redis Cluster absorbing ~80% of read volume in-memory.
