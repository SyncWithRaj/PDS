Mitigation Strategy: Implemented SQS ingestion queue buffering and client-side exponential backoff retries.

⚠️ LLM inference latency blocking search queries

Mitigation Strategy: Change the connection protocol to HTTPS / AWS SDK polling, or replace Amazon SQS with Amazon MQ (RabbitMQ engine) if AMQP is strictly required.

⚠️ [DEF-02] The Ingestion Service and Hybrid Search Engine are configured to connect to Aurora Postgres via gRPC / HTTP/2.

Mitigation Strategy: Modify the connection to use the native PostgreSQL Wire Protocol (TCP port 5432) with an intermediate connection pooler like PgBouncer.

Mitigation Strategy: Enforce the use of native RESP protocol over TCP (port 6379) using standard Redis client libraries.
