6. Bottleneck Identification & Mitigation Strategies

⚠️ High-frequency WebSocket connection churn exhausting ephemeral ports and memory

Mitigation Strategy: Configured ElastiCache Redis connection pooling across 4 shard nodes with keepalive probes and load-balanced Go WebSocket gateways.

⚠️ Write amplification during celebrity post fanout clogging consumer queues

Mitigation Strategy: Implemented partition sharding on Kafka topics and offloaded celebrity feeds to a pull-based hybrid model where timelines are evaluated on-read for accounts exceeding 100K followers.

⚠️ Graph traversal locking under intense social interaction spikes

Mitigation Strategy: Implemented read-through caching in Redis for top-tier user connection lists, reducing direct graph database query load by 80%.

⚠️ [DEF-01] Fanout-on-write model can cause write amplification for celebrity users with millions of followers.

Mitigation Strategy: Implement a hybrid fanout model where celebrity posts use a pull-based (fanout-on-read) approach combined with the push-based approach.
